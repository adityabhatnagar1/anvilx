## What is anvilx?

anvilx is a command-line AI router designed to sit between you and multiple models.

Instead of being locked into a single provider, anvilx lets you orchestrate local and cloud intelligence from one terminal-native interface.

Whether the task needs speed, reasoning, privacy, or a second opinion, anvilx aims to send work to the right model and return a unified result.

---

## Why?

Most AI tools assume:

- One model
- One provider
- One workflow

Real-world usage is messier.

Some tasks are better on local models.
Some require larger cloud models.
Some benefit from multiple perspectives.

anvilx exists to make that orchestration feel simple.
