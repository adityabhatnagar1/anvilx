A Multi-LLM CLI Router · Built in Rust

Route smarter.
Spend lesser.

A Rust-based CLI tool that optimizes your AI spend by routing, merging-demerging, and caching prompts across multiple providers and models. Every small API cost can crazily skyrocket and drain your wallet, to stop that my tool helps you!

$ bro ask "what is a prime number?"
→ routing to ollama/llama3.2 (short simple question → local model)
┌─ ollama/llama3.2 (0 + 0 tokens) $0.0000 3120ms
│ A prime number is a natural number greater than 1...
└──────────────────────────────
 
$ bro ask "implement a binary search tree in Rust"
→ routing to claude-haiku-4-5 (code task → Claude Haiku)
┌─ claude-haiku-4-5 (120 + 344 tokens) $0.0005 412ms
 
$ bro stats
Total queries : 127 · Total cost : $0.2341 · Avg/query : $0.0018
~30-50% avg cost saved
COSTING $0 local inference
MANY providers

Routing Logic

Signal Model Cost
<20 words, no code ollama/llama3 FREE
Code keywords claude-haiku ~$0.001
Normal question gpt-4o-mini ~$0.002
150+ words or complex gpt-4o ~$0.05

Why this matters: One OpenAI engineer spent $1.3M in 30 days on API tokens. Meta burned 60 trillion tokens in a single month. Agentic tasks consume up to 1,000× more tokens than simple chat. bro routes the cheap stuff to cheap models, automatically.

Crate Stack

clap
v4 · features = ["derive"]
CLI interface. Define commands as structs with derive macros. Handles bro ask, bro history, flags like --model gpt.
tokio
v1 · features = ["full"]
Async runtime. Fire all provider calls simultaneously with tokio::join!. The engine that makes parallel HTTP requests possible.
reqwest
v0.12 · features = ["json"]
HTTP client. Calls OpenAI, Anthropic, Gemini, Ollama. The json feature auto-serializes request bodies.
serde + serde_json
v1 · features = ["derive"]
Rust structs ↔ JSON. Derive Serialize, Deserialize on your request/response types. Essential for every API call.
rusqlite
v0.31 · features = ["bundled"]
SQLite for Rust. Logs every query, token count, cost, and latency to ~/.bro/history.db. Bundled = zero install needed.
colored
v2
Terminal colors. "$0.0005".green(), "Error".red(). Makes the cost badges and routing decisions actually readable.
anyhow
v1
Ergonomic errors. anyhow::Result<T> everywhere. The ? operator propagates failures cleanly without custom error types.
dotenv
v0.15
Load API keys from .env at startup. Keys stay out of source code. One call: dotenv::dotenv().ok().
toml + chrono + dirs
v0.8 · v0.4 · v5
Config file parsing, timestamps for the SQLite history, and cross-platform home directory for ~/.bro/.
